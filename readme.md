# ✍️ AI Content Assistant

An AI-powered web application built with Streamlit and Groq (Llama models) that generates tailored social media posts, captions, and hashtags based on specified target platforms, audiences, and tones.

🚀 **Live Demo:** [Click here to view the app](https://talhakhan1506-ai-content-assistant-app-qtis3c.streamlit.app)

## Features
- **Platform Specificity:** Tailored prompts for LinkedIn, Twitter/X, Instagram, and Facebook.
- **Custom Parameters:** Fine-tune target audience, topic, tone, and content structure.
- **Ultra-Fast Generation:** Powered by Groq Llama-3 models.
- **Secure Integration:** Built-in Streamlit Secrets management for API key security.

## Tech Stack
- **Frontend / Web Framework:** Streamlit
- **LLM API:** Groq SDK (Llama 3)
- **Language:** Python 3.10+
- **Deployment:** Streamlit Community Cloud
